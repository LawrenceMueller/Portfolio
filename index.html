Snowball - Recent Project

An anonymous web forum built with Go, PostgreSQL and htmx

Source code on GitHub Read the project spec

Snowball was built entirely through Claude Code. I have used this project to learn the ins and outs of AI-assisted development.

Building Snowball taught me that AI-assisted development can make an experienced programmer much faster, but it changes where the actual work for the developer is. With AI writing most of the code, my job became making sure it was right: reviewing what it wrote, testing it, and documenting decisions so the project stays maintainable.

The best lesson I have taken away is to keep a project spec that grows with the project. It holds the choices I made on architecture, the database schema, the rules the data has to follow, and a log of every decision. Claude starts every session from it. Here's a small piece of it:

Accounts without email

argon2id password hashing, hashed session tokens and single-use recovery codes.

Defenses built in

CSRF protection, a strict content security policy, and per-IP and per-account rate limits.

160+ tests

Unit, database, concurrency and fuzz tests. Fuzzing caught an open redirect and a memory-exhaustion bug.

Tested at scale

Load-tested against a seeded database of 100,000 posts, 1.2 million comments and 5.8 million votes.
